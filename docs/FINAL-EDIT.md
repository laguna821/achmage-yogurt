# 0.6.0 — 최종 문서 편집과 자막 정규화

자동 정리는 원문 확보 → 구간별 내용 정리·검수 → **문서 전체 최종 편집**까지 진행합니다. 강의는 개념·근거·예시·절차를 연결하고, 회의는 결정과 제안·담당·기한·이견을 구분합니다. 인사·장비 점검 등은 덜어내고 실제 내용을 충분히 남깁니다. 내용과 무관한 고정 분량이나 도식 수는 요구하지 않습니다.

## 읽기와 근거

- 최종 영상 문서, MD 복사, MD 내보내기에는 영상 위치 링크를 자동으로 붙이지 않습니다.
- **원문 근거·타임라인 보기**에서 문단의 T/V 근거와 원본 위치를 확인합니다. 내부 근거는 삭제하지 않습니다.
- 실제 일정·시각·날짜·기간·숫자는 내용이므로 보존합니다. 모든 `12:30` 문자열을 지우는 방식이 아닙니다.
- 구간별 초안의 모든 주제가 최종 편집의 어느 절에 대응하는지 검사합니다. 대응이 누락되거나 모델 응답이 불완전하면 기존 문서를 유지합니다. 이는 사실 정확도를 자동 보장하는 검사가 아닙니다.
- 기존 사용자가 편집한 정리본은 새 후보로 제안합니다. 이미 저장된 결과를 업데이트 설치만으로 다시 쓰지 않습니다. 새 최종 편집을 적용하려면 해당 기록에서 다시 정리하세요.

## 빠른 자막 처리

WebVTT의 공백만 있는 본문 줄을 잘못 종료 처리하던 오류를 고쳤습니다. 인라인 단어 시각과 인접 cue를 이용해 확인된 롤링 재표시만 제거합니다. 새 시각이 붙은 실제 반복과 일반 자막의 반복은 보존합니다. 원문 언어의 자막을 자동 번역 트랙보다 우선하며, 자막이 유효하면 Whisper 재전사를 하지 않습니다. YouTube 제한·자막 미제공 시 기존 음성 fallback은 유지됩니다.

기존 가져오기의 원본 VTT도 다시 다운로드 없이 사용할 수 있습니다. 가져오기 영수증과 현재 전사문이 일치할 때만 파생 정규화를 수행하며 DB의 원문은 바꾸지 않습니다. 전사문을 수정했다면 수정본을 우선합니다. 최종 결과에는 당시 사용한 근거 전사를 함께 보관합니다.

로컬의 긴 한국어 강의 3건에서 입력 글자 수가 **64.68–65.35%** 줄고, 24,000자 기준 텍스트 구간이 **7/7/4 → 3/3/2**로 줄었습니다. 이 수치는 입력량 측정이며 전체 소요시간 개선률이 아닙니다. 화면 분석, AI 추론 강도, 구독 대기 시간은 별도로 영향을 줍니다. 화면이 필요 없으면 정리 설정에서 화면 판독을 끌 수 있습니다.

## 형식과 호환성

회의·강의 정리의 최종 원문 검수에도 같은 편집 규칙을 적용합니다. 개인 기록에는 실제 절차 번호와 실천 체크리스트를 허용합니다. 이를 위해 앱에 포함된 transcript lint에 명시적 `--reader-format` 옵션을 추가했습니다. 원래 스킬의 기본 lint와 공식 회의록 profile은 그대로이며, 설치된 외부 스킬이나 Obsidian 원본은 수정하지 않습니다. 앱 manifest는 수정된 검증 스크립트의 SHA256을 고정합니다.

큰 문서를 처리할 문맥 공간이 부족하거나 최종 JSON이 잘리면 이전 문서·완료 캐시를 유지하고 오류를 표시합니다. 문서 품질과 사실관계는 검토가 필요합니다. 화면 판독과 외부 심층 조사는 기존의 선택 기능입니다.

이번 버전은 Linux에서 실행 검증하며 Windows와 macOS는 교차 빌드입니다. 해당 실기기의 설치·녹음·권한 확인을 대신하지 않습니다. 서명·Apple 공증은 포함하지 않습니다.
