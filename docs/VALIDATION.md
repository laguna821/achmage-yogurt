## 보존과 제한

테스트에 쓴 실제 음성, 전사 원문, 기존 DB·자격 증명은 저장소나 릴리스에 포함하지 않습니다. 화면 캡처는 가상의 테스트 문서만 담습니다. 모델 파일은 별도 로컬 프로필에 보관하며 설치본에는 들어 있지 않습니다.

새 앱은 기존 Yogurt와 별개 설치·설정·로그인 항목을 사용합니다. 구독 AI의 로그인 정보는 공식 Codex 클라이언트가 해당 기기에서 관리합니다. 기존 네이티브 캡처/Whisper 헬퍼를 바꾸지 않아 Windows/Mac 교차 빌드에서는 검증된 원래 배포본의 헬퍼를 그대로 사용했습니다.

Mac Intel·DMG, iOS/웹 앱, 새 ASR 엔진, 스캔 PDF OCR, 카카오톡 직접 연결, 유료/비공개 영상 로그인은 이번 구현의 완료 범위가 아닙니다. 외부 영상 서비스의 차단·로그인 요구는 파일 가져오기로 대체할 수 있습니다.
