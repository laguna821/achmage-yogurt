# Plaud 원음 가져오기

데스크톱 0.6.2-achmage.1부터 **전체 기록 → Plaud에서 가져오기** 또는 **설정 → 자료 연결 → Plaud 연결**에서 시작합니다.

1. Plaud 연결을 누르고 기본 브라우저에서 본인 계정으로 로그인·승인합니다.
2. Yogurt로 돌아와 녹음을 선택합니다. Plaud 클라우드에 동기화된 파일이 표시됩니다.
3. **가져와서 로컬 전사**를 누르면 원음을 내려받아 기존 음성 가져오기 대기열에 등록합니다.
4. 전사가 완료되면 기록의 **정리** 탭에서 맥락 자료를 추가하고 정리를 시작합니다.

이미 Plaud에서 전사된 녹음도 원음을 받아 Yogurt의 선택된 로컬 음성 모델로 새로 전사합니다. Plaud 전사문과 요약은 가져오지 않습니다. 이 기능은 Plaud 전사를 요청하지 않으며 원격 원본을 변경하지 않습니다. Plaud 자체 자동 전사를 원하지 않으면 Plaud 앱의 새 녹음 자동 요약 설정도 꺼야 합니다.

목록은 20개씩 표시됩니다. 다운로드 진행량과 중단 버튼을 제공하며, 최대 파일 크기는 기존 가져오기와 같은 10GB입니다. 완료되지 않은 다운로드는 전사 대기열에 들어가지 않습니다. 같은 파일을 다시 누르면 기존 가져오기 작업을 열며, 실패한 전사는 **가져오기 작업 → 다시 시작**으로 재개합니다.

## 연결과 저장

- 공식 HTTP MCP `https://mcp.plaud.ai/mcp`, OAuth PKCE S256, 일회성 state 검증, 로컬 loopback callback을 사용합니다. 별도 API 키나 Plaud npm CLI 설치는 필요하지 않습니다.
- MCP 호출은 `list_files`, `get_file`만 사용합니다. 다운로드는 `get_file`의 서명된 원음 URL로 진행합니다.
- 인증 정보는 이 컴퓨터의 앱 프로필에 저장합니다. Electron safeStorage를 사용할 수 있으면 암호화하고, 사용할 수 없으면 소유자만 읽고 쓸 수 있는 로컬 파일로 저장합니다. GitHub나 앱 백업에 인증 정보를 넣지 않습니다.
- **이 컴퓨터 연결 해제**는 로컬 인증 정보를 삭제합니다. Plaud 계정 측의 권한 철회를 대신하지는 않습니다. 이미 내려받은 오디오는 남습니다.
- 현재 모바일 웹앱에는 이 기능이 없습니다.

## 검증 범위

타입 검사, Plaud/기존 가져오기 단위시험 14개, Electron 화면시험 2개를 통과했습니다. 로컬 패키지에서는 별도 격리 프로필로 가져오기 버튼과 자료 연결 설정 화면을 확인했습니다. 시험은 격리 프로필과 가짜 녹음 데이터로 실행하며 유료 AI를 호출하지 않습니다.

공식 서버의 실제 앱 등록 요청에서 HTTP 201, public client 인증 방식, loopback callback 허용을 확인했습니다. **사용자 계정 로그인 후 실제 녹음 목록·원음 다운로드는 아직 검증하지 않았습니다.** OAuth 상태 검증, 토큰을 이용한 MCP 초기화·도구 호출, 다운로드 중단·미완성 응답·중복 등록은 모의 서버로 검증했습니다.
